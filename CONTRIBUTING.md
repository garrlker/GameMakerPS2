# Contributing to GameMaker PS2 Runner

Thank you for considering contributing to GameMaker PS2 Runner! We welcome contributions of all kinds.

## How Can I Contribute?

### Reporting Bugs

- Open an [issue](https://github.com/garrlker/GameMakerPS2/issues) describing the bug.
- Include clear steps to reproduce, expected behavior, and screenshots/logs if possible.

### Suggesting Enhancements

- Open an issue with the `[Feature Request]` prefix in the title.
- Describe your idea and why it would benefit the project.

### Pull Requests

1. **Fork** the repository.
2. **Create** a new branch for your changes.
3. **Make** your changes with clear and descriptive commit messages.
4. **Test** your code thoroughly.
5. **Submit** a Pull Request with a detailed description of what you added or changed.

#### Pull Request Guidelines

- Keep PRs focused and limited in scope.
- Reference related issues in your PR description.
- Ensure your code follows existing project style.
- Update documentation as appropriate.

## Code of Conduct

Please be respectful and considerate in all project interactions
