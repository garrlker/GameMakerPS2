## Gamepad

Supported Platforms: PS2, Web

#### Supported GM Functions

* joystick_check_button(joystick, button)
* joystick_zpos(joystick)
* joystick_xpos(joystick)
* joystick_ypos(joystick)
* joystick_rpos(joystick)
* joystick_upos(joystick)
* joystick_vpos(joystick)

#### Gamepad Buttons

* 1 = CROSS
* 2 = CIRCLE
* 3 = SQUARE
* 4 = TRIANGLE
* 5 = L1
* 6 = R1
* 7 = L2
* 8 = R2
* 9 = SELECT
* 10 = START
* 11 = L3
* 12 = R3
* 13 = UP
* 14 = DOWN
* 15 = LEFT
* 16 = RIGHT

#### Issues

* Currently only 1 joystick is supported
  * Supported a 2nd gamepad was causing the engine to stall while waiting on PS2
